# Dativ

## Rules

|                         | Maskulin                      | Neutral                       | Feminin                         | Plural                            |
|-------------------------|-------------------------------|-------------------------------|---------------------------------|-----------------------------------|
| Nominativ (wer? / was?) | der / ein / kein Mann         | das / ein / kein Kind         | die / eine / keine Frau         | die / – / keine Leute             |
| Akkusativ (wen? / was?) | den / einen / keinen Mann     | das / ein / kein Kind         | die / eine / keine Frau         | die / – / keine Leute             |
| Dativ (wem?)            | dem / einem / keinem Mann     | dem / einem / keinem Kind     | der / einer / keiner Frau       | den / – / keinen Leute**n**       |

> Maskulin and neutral are the same in Dativ.
> Dativ plural: noun gets **-n** at the end → Leute**n**, Freunde**n**.
> Exception: nouns with plural **-s** don't get -n → Autos (not Autosn).
> Possessivartikel work like `kein` → meinem, meiner, meinen …

## Examples

- Ich helfe **dem Mann**. (I help the man.)
- Sie gibt **einem Kind** ein Buch. (She gives a book to a child.)
- Er dankt **seiner Freundin**. (He thanks his girlfriend.)
- Wir fahren mit **zwei Autos**. (We drive with two cars.)

## Mistakes

`einem` is singular — noun stays singular:
- mit **einem Freund** (with a friend) — not ~~mit einem Freunden~~
- mit **Freunden** (with friends) — plural Dativ, no article

`das Mädchen` is neuter → Dativ takes `einem`, not `einer`:
- mit **einem Mädchen** (with a girl) — not ~~mit einer Mädchen~~
