# Perfekt mit haben

## Rules

Die meisten Verben benutzt man in der Vergangenheit mit dem Perfekt.
Formation: **haben** (Position 2) + **Partizip Perfekt** (Ende)

| Position 2 | Ende (Partizip Perfekt)  |
|------------|--------------------------|
| habe       | gearbeitet               |
| habe       | gegessen                 |
| hast       | gespielt?                |


## Partizip Perfekt Patterns

| Type                     | Pattern                   | Example                          |
|--------------------------|---------------------------|----------------------------------|
| Regular                  | ge- + stem + -t           | arbeiten → ge**arbeit**et        |
| Irregular                | ge- + new stem + -en      | essen → **gegessen**, trinken → **getrunken** |
| Trennbare Verben         | prefix + ge- + stem + -t/-en | einkaufen → **einge**kauft    |
| Verbs ending in -ieren   | stem + -t (no ge-)        | telefonieren → telefonier**t**   |
| Inseparable prefix (be-, ver-, er-…) | stem + -t/-en (no ge-) | besuchen → besuch**t**, vergessen → vergess**en** |


## Tips

Time expressions for Perfekt: vor einer Stunde, gestern, vor zwei Wochen, vor fünf Jahren
Time expressions for Präsens: jetzt, heute


## Examples

| Perfekt (gestern)                          | Präsens (heute)                    |
|--------------------------------------------|------------------------------------|
| Was **hast** du gestern **gemacht**?       | Was **machst** du heute?           |
| Ich **habe** zehn Stunden **gearbeitet**.  | Heute arbeite ich nicht.           |
| Ich **habe** ein Brot **gegessen**.        | Ich esse im Restaurant.            |
| Ich **habe** einen Tee **getrunken**.      | Ich trinke ein Glas Rotwein.       |
| Ich **habe** geschlafen.                   | Dann gehe ich tanzen.              |
