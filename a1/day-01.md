## 1. Grammar Rule

The verb is always in the **second position** in a declarative sentence.
- Ich **bin** Softwareentwickler.

## 2. Verbs (Verben)

### heißen – to be called

|  |
|---|
| Ich heiße |
| Du heißt |
| Er/Sie/Es heißt |
| Wir heißen |
| Ihr heißt |
| Sie/sie heißen |

**Perfect:** hat geheißen

### sein – to be

| |
|---|
| Ich bin |
| Du bist |
| Er/Sie/Es ist |
| Wir sind |
| Ihr seid |
| Sie/sie sind |

**Perfect tense:** ist gewesen

### Asking and Answering Names

Q: Wie ist Ihr Name? / Wie ist dein Name? [How (What) is your name?]

A: Mein Name ist Max.

Q: Wer sind Sie? / Wer bist du? [Who are you?]

A: Ich bin Max.

Q: Wie heißen Sie? / Wie heißt du? [How you should be called?]

A: Ich heiße Max.

Example:

**A:** Hallo! Wie heißt du?

**B:** Ich heiße Anna. Und du?

**A:** Ich heiße Max. Freut mich!

**B:** Freut mich auch!
