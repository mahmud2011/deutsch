## 1. Grammar Rule

The verb is always in the **second position** in a declarative sentence.
- Ich bin Softwareentwickler.

## 2. Verbs (Verben)

### heißen – to be called

|  |
|---|
| Ich heiße |
| Du heißt |
| Er/Sie/Es heißt |
| Wir heißen |
| Ihr heißt |
| Sie/sie heißen |

**Perfect:** hat geheißen

### sein – to be

| |
|---|
| Ich bin |
| Du bist |
| Er/Sie/Es ist |
| Wir sind |
| Ihr seid |
| Sie/sie sind |

**Perfect tense:** ist gewesen
